# Health Prediction App

## Project Overview

Health Prediction App is a web-based healthcare application developed using Flask and SQLite.

The application allows users to:

- Add patient information
- Store patient records in a database
- Update patient details
- Delete patient records
- Generate health risk predictions based on medical values

## Features

- Patient Registration
- Health Prediction
- SQLite Database Storage
- Edit Patient Details
- Delete Patient Records
- Bootstrap User Interface
- CRUD Operations

## Technologies Used

- Python
- Flask
- SQLite
- SQLAlchemy
- Bootstrap 5
- HTML
- CSS
- GitHub

## Health Prediction Logic

The application predicts patient health risks using:

- Glucose Level
- Haemoglobin Level
- Cholesterol Level

Possible Results:

- Normal
- High Diabetes Risk
- High Cholesterol Risk
- Low Haemoglobin Risk

## How to Run

1. Clone the repository

```bash
git clone https://github.com/gundrathithanuja/Health-Prediction-App.git
```

2. Install dependencies

```bash
pip install flask
pip install flask-sqlalchemy
```

3. Run application

```bash
python app.py
```

4. Open browser

```text
http://127.0.0.1:5000
```
